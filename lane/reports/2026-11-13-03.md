## Root cause reproduced locally

`generate()` previously passed the entire provider text directly to
`JSON.parse()`. An Anthropic-shaped response containing a single Markdown JSON
fence around an otherwise correct answer failed parsing. It returned measured
usage with `value:null`; the handler then settled a rejected receipt and returned
502 `BAD_PROPOSAL` **before `validateAnswer()` ran**. The same exact excerpts as
bare JSON were accepted. A paraphrase was correctly rejected by grounding.

`tests/fixtures/docent-haiku-response.json` contains the reproduction: one exact
sentence from the permitted public `lead` block, a `blockId`, a text content
block, `end_turn` and synthetic usage. It is a hand-authored fixture, **not a
capture of Silver's response**. The original response was deliberately not
retained, and BAD_PROPOSAL also covers other failure paths. This establishes a
local defect and a candidate explanation, not the actual live call's root cause.
