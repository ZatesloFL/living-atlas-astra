## Kit contract v2 — standing

Draft record changes and published record versions carry the declaration and these references on the same authored Place or Thing. Projections refer to those records. The shape also applies to Things held inline as A6 blocks.

```text
content:                    { [dimension]: { amount, graphicness } }
standing:                   {
  declarationRef:           { versionId, receiptRef } | null,
  measurementRecordsRef:    MeasurementRecordsRef | null,
  declarationRecordReadingRef: ReadingRef | null
}
```

- **Declare.** Keep the existing `content` field for the six declared pairs, each axis 0–3. Existing `admission` fields carry a Place’s declared door terms. The canonical subject is `{ placeId }` for a Place or `{ placeId, thingId }` for a Thing. The declaration reference binds that subject and its exact authored record version to the signed declaration Receipt. Use the version in `Revision.ownedRecordVersions`. A general draft, interview, or proposal Receipt does not prove a published declaration.
- **Measure.** `measurementRecordsRef` refers to the shared collection for the subject. The collection resolves to receipt-backed measurement records that identify the exact declaration they checked. Steward readings and audience readings resolve through that collection with their measurer class intact. A contest adds a new Receipt and supersedes the outcome while retaining the original. Shared access and crossing rules decide which readings apply, including the visitor’s option to consult audience readings when no Steward has measured.
- **Read the declaration record.** `declarationRecordReadingRef` resolves the current reading of the subject’s declaration record through the shared derivation. A Place’s reading belongs to that Place. The Creator’s declaration record resolves separately. Lane A’s shared implementation supplies and resolves the references. Builder carries them as read-only data and accepts declaration and measurement evidence only through that implementation.
- **Draft, publish, and restore.** A private draft may carry proposed paired declarations. New or changed unpublished material has no public declaration Receipt or standing from the draft. An inherited reading, if shown alongside changed material, identifies the prior published version it describes. Public publication binds a new declaration to a signed Receipt and record version. When published material and its declaration stay on the same authored version, a layout-only change keeps its links. Publication and restore retain the prior Receipts and the versions they describe.
- **Existing records and references.** Missing standing links in a v1 starter or an unmeasured record resolve to the applicable `unmeasured` state. An existing `measured` value remains a compatibility input under the shared rules and supplies no measurement Receipt on its own. A referenced public Place or Thing resolves its standing at the origin under source access and revocation. Its host placement gains no declaration record from the inclusion.
- **Privacy and copy.** Standing starts at public publication. The shared resolver protects private or unpublished declarations, visiting history, Lens settings, and the crossing Receipt used to establish audience eligibility. Publication exposes the declarations and outcomes allowed by file 26. Builder copy and reports use file 26’s terms, including **Declared · Steward · Audience**, **gap**, and **unmeasured**. The visitor’s and owner’s standing rules consume the shared reading.
