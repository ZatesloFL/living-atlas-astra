## Reproducing the synthetic live check

`scripts/verify-docent-live.cjs` is a manual script, outside `npm test`. It refuses to run unless `ATLAS_ALLOW_LIVE=1`, accepts only fixed `baseline`, `typed` or `unknown` cases, and makes one paid synthetic ask per invocation. It captures only public request bodies/proxy answers and sanitized network status; never session bootstrap values, headers or raw provider bodies. Set `ATLAS_PLAYWRIGHT_MODULE` to the installed Playwright module. On this Cloud machine only, `ATLAS_PROXY_CA=/usr/local/share/ca-certificates/environment-proxy-ca.crt` scopes the already supplied CA pin to the disposable Chromium process. Normal browsers use their default certificate trust when that option is absent.
