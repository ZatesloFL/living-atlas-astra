## Kit contract v2 — owner age rules

The following fields belong to the authored Place or Thing version. A projection refers to that version. A public reference uses the origin’s terms.

```text
content:   PairedScores
standing:  { declarationRef, measurementRecordsRef, declarationRecordReadingRef }
admission: {
  mode: "threshold" | "filtered",
  minimum?: PairedScores,
  measuredMinimum?: PairedScores,
  ageRule?: { band: AgeBand, guardianExceptionBand?: AgeBand },
  price?: DeclaredDoorPrice
}
AgeBand: {
  lower?: { op: "gte" | "gt", years: integer },
  upper?: { op: "lte" | "lt", years: integer }
}
```

An absent `ageRule` means the owner set no age term. Each supplied band has at least one bound. Bounds use nonnegative integer thresholds and must describe a nonempty band. Strict and inclusive operators let an owner distinguish “over 65” from “65 and over.” The existing content mode and minima sit alongside this term. `price` is the declared door price, whose data format and mechanics are reserved for the commerce order.

| Owner’s declared term | Predicate data |
|---|---|
| No under 18 | Lower bound `gte 18` |
| Only over 65 | Lower bound `gt 65` |
| Ages 13–17 only | Lower bound `gte 13` and upper bound `lte 17` |
| 18+, or ages 13–17 with a guardian exception | Ordinary band `gte 18`. Alternate band `gte 13` and `lte 17`, requiring a current scoped guardian exception. |

- **Pre-flight and Receipt.** Show the declared age term alongside the content threshold and declared price. Bind it to the authored version’s declaration Receipt. A blocked age predicate writes a Receipt identifying the subject, declared term and outcome under the visiting-history privacy rules. The kit holds only predicate data. The shared door evaluator requests predicate answers from attested Second Look account facts. Birthdates, age attestations, account documents and the visitor’s Lens settings stay outside the kit and blocked-crossing Receipt.
- **Every layer must permit.** Unknown age fails a supplied bound, including an upper bound. With no age term, the other layers still decide entry. The age rule applies to the exact subject and composes with containing doors, legal floors, other owner terms, guardian ceilings and the visitor’s Lens. Both threshold and filtered admission apply it. A current guardian exception counts toward the alternate band only when the owner declared that band. All other layers still bind.
- **Builder boundary.** Builder carries declared terms through draft and publication and uses the shared evaluator in visitor preview. Shared rules own predicate evaluation, Receipts for age-rule blocks, and any compatibility mapping for legacy `minAge`. This filing leaves runtime enforcement to the applicable later order.
